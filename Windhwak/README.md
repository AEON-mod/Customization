## 🚀 Getting Started

### Step 1: Download & Install Windhawk

1. Head to [windhawk.net](https://windhawk.net) and download the installer
2. Run the installer and launch Windhawk
3. Create a free account (optional, but syncs settings across devices)

### Step 2: Import Your First Mod

#### ✅ Recommended: Import from Clipboard

1. **Find** the mod file you want (e.g., `Notification Styler Codes for Dark Mode.txt`)
2. **Select all** the code (`Ctrl+A`) and **copy** it (`Ctrl+C`)
3. **Launch** Windhawk
4. Click **+ Add mod** → **Import from clipboard**
5. **Paste** the code (`Ctrl+V`)
6. Click **Install mod**
7. **Restart** Windows Explorer when prompted

#### Alternative: Manual Creation

1. Open Windhawk → **+ Add mod** → **Create custom mod**
2. Paste the code into the editor
3. Give it a descriptive name (e.g., "Dark Notification Styler")
4. Click **Save** → **Install**

## 🛠️ Customization Guide

### Adjust Transparency

1. Open Windhawk → Find your transparency mod
2. Click the mod → **Settings**
3. Drag the **Opacity slider** (0–255 range)
4. Click **Save** and enjoy!

### Change Colors

1. Open Windhawk → Select your Taskbar/Start Menu mod
2. Go to **Settings**
3. Update colors using hex codes:
   - Dark: `#1E1E1E`, `#0078D4`, `#1F1F1F`
   - Light: `#FFFFFF`, `#F3F3F3`, `#E5E5E5`
4. Click **Save**

### Toggle Mods On/Off

Click the toggle switch next to any mod in Windhawk's list. No reinstall needed!

### Remove a Mod

1. Find the mod in Windhawk
2. Click **Uninstall**
3. Restart Windows Explorer

## 🔧 Troubleshooting

### Common Issues & Solutions

| 🚨 Issue | ✅ Solution |
|---------|-----------|
| Changes not visible | Restart Windows Explorer (Task Manager → Right-click → Restart) |
| Black screen/glitches | Disable mod → Uninstall → Reinstall |
| Start Menu not responding | Uninstall Start Menu mod, restart Explorer |
| Taskbar disappears | Uninstall Taskbar Styler, restart Explorer |
| Wrong notification style | Make sure you're using the right theme mod |
| Mod won't install | Update Windhawk to v1.0+ |
| Settings not saving | Run Windhawk as Administrator |

### 🔄 Full Reset

If problems persist:

1. Open Windhawk
2. **Uninstall all mods**
3. **Restart your PC**
4. **Reinstall mods one at a time** (helps identify conflicts)

## ✨ Best Practices

| ✅ Do | ❌ Don't |
|------|---------|
| Match notification codes to your theme | Mix dark & light notification mods |
| Test mods individually first | Apply all mods at once |
| Restart Explorer after install | Edit `.txt` files before importing |
| Create a system restore point | Use on production systems without testing |
| Run Windhawk as Administrator | Share files without documentation |

## ⚠️ Important Disclaimer

**Use at your own risk.** Modifying Windows UI components may cause instability. While thoroughly tested on Windows 10/11 with Windhawk v1.3+:

- Always create a **system restore point** before installation
- Test on a non-critical system first if possible
- Disable all mods if you experience issues
- Keep Windhawk updated
