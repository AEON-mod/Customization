## 🎯 Overview

Welcome to the **AEON-mod Customization Suite**. This repository serves as a centralized hub for production-ready, highly curated customization scripts, mods, and themes. 

Instead of bloated software, this suite focuses on lightweight, modular enhancements that handle heavy lifting automatically—from visual revamps (glassmorphism, advanced blur effects) to deep productivity automation (gestures, terminal tweaks, and system-level overhauls).

---

## 🎨 Design Philosophy

We believe in **beauty with purpose**:
- **Aesthetic:** Moody, high-contrast designs carefully optimized for dark mode.
- **Typography:** Clean, developer-friendly fonts for maximum legibility.
- **Minimalism:** Decluttered interfaces with a strong visual hierarchy.
- **Modernity:** Advanced use of transparency, Mica, and glassmorphism.

---

## 🚀 How to Use This Repository

Because this suite is strictly modular, you can pick and choose exactly which customizations you want to apply without any dependency overlap. 

1. **Explore:** Browse the subdirectories in this repository. Each folder acts as an independent, standalone module.
2. **Read:** Open the `README.md` inside any specific module's folder for detailed instructions, prerequisites, and setup guides.
3. **Deploy:** Follow the specific module's guide to safely inject the customization into your system.

*No master installation script is required—simply navigate to the tool you need and deploy it!*

---

## 🛡️ Safety & Disclaimer

Modifying system UI and behaviors carries inherent risks. 
- Always create a **System Restore Point** or backup your configurations before applying changes.
- Ensure you read the specific module's documentation thoroughly.
