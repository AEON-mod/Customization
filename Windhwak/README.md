## 🎨 About This Collection

This folder contains custom styling configurations for **[Windhawk](https://windhawk.net/)**, the ultimate tool for tweaking Windows programs and the OS itself. These themes inject elegant, modern visuals directly into your Windows UI.

**Included Themes:**
- 🌫️ **Blur-Translucent-Theme:** Adds a smooth, frosted glass blur effect to various UI elements.
- 🐈‍⬛ **Dark-Catppuccin-Theme:** A soothing pastel dark theme inspired by the popular Catppuccin palette.
- 🪟 **Window-Glass-Theme:** Recreates a stunning, transparent Aero Glass aesthetic for modern Windows.

---

## 🚀 How to Apply

Follow these simple steps to apply any of these themes to your system:

### 1️⃣ Prerequisites
1. Download and install **[Windhawk](https://windhawk.net/)**.
2. Open Windhawk and go to the **Explore** tab.
3. Install the specific mod that these themes target (usually **"Windows 11 Taskbar Styler"** or **"Start Menu Styler"**).

### 2️⃣ Importing a Theme
1. Navigate into the folder of the theme you want (e.g., `Dark-Catppuccin-Theme`).
2. Open the configuration file (`.json` or `.txt`) inside and **copy all of its contents**.
3. Open Windhawk, click on your installed mod, and go to **Settings** (or the Advanced tab).
4. Look for the **Import** button or the raw configuration text box.
5. **Paste** the copied code and click **Save**.

### 3️⃣ Enjoy
- Restart Windows Explorer if prompted to see the changes fully take effect!
- *To revert, simply clear the code box or click "Reset to defaults" in Windhawk.*
